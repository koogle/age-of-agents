# Visual references

**Primary since 2026-10-01:** `diorama_primary.webp`, a soft 3D tilt-shift diorama of a Greek island with an almost hidden interface (globe minimap, round medallion buttons). Jakob chose it as the look for the fully 3D game. A second diorama image Jakob shared in chat (not saved here) refines the interface layout: a menu coin top-left, small coins top-right, a parchment globe map bottom-right with coins on its shoulder, and one slim command bar at the bottom. The images below are earlier palette references.

Midjourney images made by Jakob on 2026-10-01 to define the target look. `mediterranean_4.webp` is the primary reference: a Moebius-style inked comic of a sunlit Mediterranean landscape under cream, ink-ruled paper UI with coin medallions and illustrated card tiles. The others support the palette (turquoise water, yellow-green and ochre land, limestone, cypresses, terracotta roofs, white marble) and, in `mediterranean_5.webp`, a terracotta command bar with round icon buttons.

These are direction only; nothing here is loaded by the game.
