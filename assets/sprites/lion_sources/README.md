# Lion sprites

Lioness (pride member) and maned lion (pride leader), four poses each: idle,
walk, attack windup, attack strike, facing right and mirrored in the renderer.
Generated 2026-10-09 with FAL `fal-ai/nano-banana/edit` against the approved
boar sheet, the NPC-matched wolf/bear attack sheet and the guard, then cut out
with `fal-ai/birefnet/v2`. Prompts, references, request IDs and rejected drafts:
`provenance.json`. Run `python3 scripts/pack_wildlife.py` to repack.

These are draft-1 sources (512px cells, no OpenAI refinement yet). See the
[lion review](../../../docs/verification/lions/README.md) for the style gate.
