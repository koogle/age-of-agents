# Giant snake sprites

Three ambushers, four poses each (rest, move, attack windup, strike), facing
right and mirrored in the renderer: the **rock python** (regular, lies up near
wild resources), the **sea serpent** (shoreline) and the **marble viper** (temple
island only). Jakob picked them from six concepts on 2026-10-10 (`concepts/`).

Each concept was adapted to the family sheet with FAL `fal-ai/nano-banana-pro/edit`
(wolf/bear sheet as style reference, the concept for design and colour), given the
ink pass, and cut out with `fal-ai/birefnet/v2` (`<name>_ink_render_0.png`,
`<name>_ink_cutout.png`). Prompts, request IDs, reviews and removed passes:
`provenance.json`. Run `python3 scripts/pack_wildlife.py` to repack.
